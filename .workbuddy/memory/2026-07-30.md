## Wiki 后续产品架构建议

- Wiki 核心能力不应依赖 Git：TheThing 自身提供来源资产、反向关系索引、revision/diff/restore、扩展元数据、搜索和可视化，使普通用户无需安装或理解 Git。
- Git 适合作为可选高级适配器，用于导出为仓库、已有仓库同步、团队协作和开发者审计；不参与每次页面读写的正确性，也不作为回滚唯一来源。
- 后续推荐顺序：先实现来源→页面反向索引与内部 revision store，再做二进制资产和 frontmatter 透传；规模增长后增加全文搜索和关系视图；最后按真实需求增加 Git 导出/同步适配器。
